S4 · Condicionales

Tomar decisiones

En bloques usabas el bloque si… si no… para que el programa decidiera qué hacer. En Python es igual: se llama condicional y se escribe con if (si), elif (si no, si…) y else (si no).

Verdadero o falso: el tipo booleano

Una condición es algo que solo puede ser verdadero (True) o falso (False). Para construir condiciones comparamos valores con estos operadores:

OperadorSignificado
==¿Es igual a…? (¡ojo, son dos signos igual!)
!=¿Es distinto de…?
>¿Es mayor que…?
<¿Es menor que…?
>=¿Es mayor o igual que…?
<=¿Es menor o igual que…?

Y para combinar condiciones tenemos los operadores lógicos and (y: se cumplen las dos), or (o: se cumple al menos una) y not (no: lo contrario).

La sentencia if / else

edad = int(input("Escribe tu edad: "))
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

La sangría es obligatoria

Fíjate en dos cosas: después de la condición van dos puntos :, y las líneas de dentro se escriben con sangría (4 espacios a la derecha). Esa sangría es la que le dice a Python «esto va dentro del if». Es como encajar bloques dentro del bloque si.

Varias opciones: elif

Cuando hay más de dos caminos, usamos elif (abreviatura de «si no, si…»):

nota = float(input("Introduce una nota: "))
if nota < 5:
    print("Insuficiente")
elif nota < 6:
    print("Suficiente")
elif nota < 9:
    print("Notable")
else:
    print("Sobresaliente")

Condicionales anidados

Un condicional puede ir dentro de otro (anidado). Cada nivel lleva más sangría:

numero = int(input("Introduce un número: "))
if numero % 2 == 0:
    print("Es par")
    if numero > 100:
        print("… y además es grande")
else:
    print("Es impar")
