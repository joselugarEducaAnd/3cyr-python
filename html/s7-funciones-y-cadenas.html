S7 · Funciones y cadenas

Ordenar el código y trabajar con textos

En bloques podías crear tus propios «bloques nuevos». En Python eso son las funciones: trozos de código con nombre que puedes reutilizar. Además, en esta sesión aprenderás a manejar cadenas de texto.

Funciones propias: def

Una función se define con def, un nombre y unos paréntesis. Dentro puede recibir datos de entrada (parámetros) y devolver un resultado con return:

def saludar(nombre):
    print("¡Hola,", nombre, "!")

saludar("Ana")      # llamamos a la función
saludar("Carlos")
def area_rectangulo(base, altura):
    return base * altura

resultado = area_rectangulo(4, 5)
print("El área es", resultado)

¿Por qué usar funciones?

Para no repetir código: escribes la función una vez y la usas muchas veces. Tu programa queda más corto, más claro y más fácil de corregir.

Cadenas de texto

Una cadena es un texto entre comillas. Puedes unirlas con +, medir su longitud con len() y usar métodos útiles:

frase = "Hola Mundo"
print(len(frase))          # 10  (número de caracteres)
print(frase.upper())       # HOLA MUNDO
print(frase.lower())       # hola mundo

El método .lower() es muy práctico para comparar respuestas del usuario sin preocuparte por mayúsculas:

respuesta = input("¿Continuar? (sí/no): ")
if respuesta.lower() == "si":
    print("Seguimos")

También puedes recorrer una cadena letra a letra con un for, y comprobar si una letra está dentro con in:

for letra in "cielo":
    if letra in "aeiou":
        print(letra, "es vocal")
