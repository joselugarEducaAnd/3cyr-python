Bucles for

Repetir sin cansarse

En bloques usabas repetir (10) para hacer algo varias veces. En Python ese bloque es el bucle for. Sirve para repetir un trozo de código un número de veces, o para recorrer una lista de valores.

El bucle for y range()

range() prepara una fila de números para que el for los recorra uno a uno. En cada vuelta, la variable del bucle (aquí numero) toma el siguiente:

for numero in range(1, 6):
    print(numero)
# Muestra 1, 2, 3, 4 y 5, uno debajo de otro (el 6 NO se incluye)

Como en el condicional, después de la línea del for van dos puntos y lo que se repite va con sangría.

range() puede usarse de tres formas:

  • range(5) → 0, 1, 2, 3, 4 (empieza en 0).
  • range(2, 6) → 2, 3, 4, 5 (desde 2 hasta 6 sin incluir el 6).
  • range(0, 20, 5) → 0, 5, 10, 15 (de 5 en 5).

También puedes recorrer una lista: varios datos entre corchetes [ ], separados por comas (como las listas de Scratch):

for nombre in ["Ana", "Beatriz", "Carlos"]:
    print("Hola,", nombre)

Sumar y contar dentro de un bucle

Muchos programas tienen que ir sumando o ir contando mientras repiten. Se hace con una variable que empieza en 0 antes del bucle y que, dentro, va creciendo. Es lo mismo que puntos = puntos + 10, pero repetido en cada vuelta:

total = 0                    # la caja empieza vacía, ANTES del bucle
for n in range(1, 6):
    total = total + n        # en cada vuelta le echas un número más
print("La suma es", total)   # DESPUÉS del bucle (sin sangría): La suma es 15

A esa variable se le llama acumulador. Si en vez de sumar el número sumas 1, tienes un contador: cuenta cuántas veces pasa algo.

aprobados = 0
for nota in [4, 7, 5, 9, 3]:
    if nota >= 5:
        aprobados = aprobados + 1   # cuenta solo las notas que aprueban
print("Aprobados:", aprobados)      # Aprobados: 3

Los dos fallos típicos

  • Poner total = 0 dentro del bucle: se vacía en cada vuelta y al final solo queda el último número.
  • Poner el print con sangría: sale la suma a medias en cada vuelta, en vez de una vez al final.

En el widget de abajo, elige sumar del 1 al 5 y mira cómo crece la caja total.

Controlar el bucle: break y continue

  • break: sale del bucle inmediatamente.
  • continue: salta al siguiente número sin ejecutar el resto de esa vuelta.
for num in range(1, 21):
    if num % 3 == 0:
        continue        # se salta los múltiplos de 3
    print(num)

Bucles anidados

Un for puede ir dentro de otro. El de dentro se repite entero por cada vuelta del de fuera:

for fila in range(1, 4):
    for asterisco in range(fila):
        print("*", end="")
    print()        # salto de línea al terminar la fila
# Dibuja:
# *
# **
# ***

Pruébalo tú: el bucle, vuelta a vuelta

Elige el programa y ejecútalo línea a línea. Mira cómo cambia la variable del bucle en cada vuelta.

En el range(1, 6) fíjate en la última comprobación: el 6 nunca llega a entrar. Al sumar, la caja total guarda en cada vuelta lo de antes más el número nuevo. En los bucles anidados, el de dentro se repite entero en cada vuelta del de fuera.
