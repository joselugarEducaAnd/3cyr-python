Programa en serio: de los bloques al texto con Python

Funciones y cadenas

Ordenar el código y trabajar con textos

En bloques podías crear tus propios «bloques nuevos». En Python eso son las funciones: trozos de código con nombre que puedes usar todas las veces que quieras. Ya conoces algunas que vienen con Python (print(), input(), int()); ahora vas a crear las tuyas. Además, en esta página verás cómo manejar cadenas de texto.

Funciones propias: def

Una función se crea con def, un nombre, unos paréntesis y dos puntos. Lo que hace va debajo, con sangría. Entre los paréntesis van los datos que recibe (se llaman parámetros):

def saludar(nombre):
    print("¡Hola, " + nombre + "!")

saludar("Ana")      # usamos (llamamos) la función: ¡Hola, Ana!
saludar("Carlos")   # otra vez, con otro dato: ¡Hola, Carlos!

Crear la función no hace nada por sí solo: el programa solo la ejecuta cuando la llamas por su nombre.

Funciones que entregan un resultado: return

Algunas funciones calculan algo y te lo entregan para que lo guardes o lo uses en otra cuenta. Eso se hace con return:

def area_rectangulo(base, altura):
    return base * altura

resultado = area_rectangulo(4, 5)
print("El área es", resultado)       # El área es 20

print enseña; return entrega

  • print enseña el resultado en la pantalla, y ahí se queda: el programa no puede usarlo.
  • return entrega el resultado a quien llamó a la función, que puede guardarlo, sumarle algo o mostrarlo.
def doble(n):
    return n * 2

x = doble(4) + 1     # doble(4) entrega 8, y 8 + 1 = 9
print(x)             # 9

Si en doble pusieras print(n * 2) en vez de return, verías un 8 en pantalla, pero doble(4) + 1 daría error: la función no habría entregado nada.

Cómo se prueba una función: llámala con datos de los que ya sabes la respuesta y muéstrala con print. Por ejemplo, print(area_rectangulo(4, 5)) tiene que mostrar 20.

Un error que verás mucho: NameError

Si escribes mal el nombre de una variable o de una función, Python no la encuentra: NameError («nombre desconocido»). Muchas veces te sugiere el bueno (Did you mean…?, «¿querías decir…?»). En la imagen: 1, el número de línea; 2, la sugerencia.

Ampliar

Cadenas de texto

Una cadena es un texto entre comillas. Puedes unirlas con +, medir cuántos caracteres tienen con len() y usar algunas órdenes que se escriben detrás del texto, con un punto (se llaman métodos):

frase = "Hola Mundo"
print(len(frase))          # 10  (cuenta también el espacio)
print(frase.upper())       # HOLA MUNDO  (todo en mayúsculas)
print(frase.lower())       # hola mundo  (todo en minúsculas)

.lower() es muy práctico para comparar respuestas del usuario sin preocuparte por mayúsculas:

respuesta = input("¿Seguimos? (s/n): ")
if respuesta.lower() == "s":
    print("Seguimos")       # vale tanto "s" como "S"

También puedes recorrer una cadena letra a letra con un for, y comprobar si una letra está dentro de otro texto con in:

for letra in "cielo":
    if letra in "aeiou":
        print(letra, "es vocal")
# Muestra: i es vocal, e es vocal, o es vocal (una en cada línea)
