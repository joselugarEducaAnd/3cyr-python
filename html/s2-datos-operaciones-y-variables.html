S2 · Datos, operaciones y variables

Números y cajas para guardarlos

Un programa trabaja con datos: casi siempre, números y textos. En esta sesión aprenderás a operar con números y a guardarlos en variables (las «cajas» que ya usabas en bloques).

Tipos de números

En Python hay dos tipos de números que usaremos:

  • Enteros (int): sin decimales. Por ejemplo 1, -2, 100.
  • Decimales o de coma flotante (float): con decimales. Por ejemplo 1.5, 3.14, -0.75.

¡Ojo con los decimales!

En Python los decimales se separan con un punto, no con una coma: se escribe 3.14, no 3,14.

Operaciones matemáticas

SímboloOperaciónEjemplo
+Suma5 + 3 → 8
-Resta5 - 3 → 2
*Multiplicación5 * 3 → 15
/División (con decimales)5 / 2 → 2.5
//División entera (sin decimales)5 // 2 → 2
%Resto de la división5 % 2 → 1
**Potencia (elevado a)5 ** 2 → 25

Para redondear un número decimal usamos round(). Por ejemplo round(3.14159, 2) da 3.14 (dos decimales).

Variables: cajas con nombre

Una variable es una caja donde guardas un dato con un nombre. Para guardar un valor se usa el signo =:

pi = 3.1416
radio = 25.5
perimetro = 2 * pi * radio
print(perimetro)

El valor de una variable puede cambiar a lo largo del programa:

puntos = 0
puntos = puntos + 10   # ahora puntos vale 10
puntos = puntos + 5    # ahora puntos vale 15
print(puntos)

Cómo nombrar bien las variables

  • Usa nombres con significado: mejor precio_total que x.
  • Sin tildes, ñ ni espacios. Para separar palabras usa el guion bajo: numero_de_alumnos (esto se llama snake_case).
  • No uses palabras reservadas del lenguaje (como print, input, for, if, while…) como nombre de variable.
