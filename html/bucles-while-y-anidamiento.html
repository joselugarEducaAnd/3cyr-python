Bucles while y anidamiento

Repetir mientras…

El bucle for repite un número conocido de veces. Pero a veces queremos repetir mientras se cumpla una condición, sin saber cuántas veces será: hasta que el usuario acierte, hasta que escriba «fin»… Para eso está el bucle while (mientras).

El bucle while

numero = 1
while numero <= 5:
    print(numero)
    numero = numero + 1
# Muestra 1, 2, 3, 4 y 5, uno debajo de otro

Antes de cada vuelta, Python comprueba la condición: si se cumple, entra; si no, el bucle termina y sigue con lo que hay debajo.

Cuidado con el bucle infinito

Dentro del while tiene que haber algo que, tarde o temprano, haga que la condición deje de cumplirse (en el ejemplo, numero = numero + 1). Si no, el bucle no termina nunca y el editor se queda colgado: recarga la página (perderás lo que no hayas guardado).

Del bloque al while

En Scratch tenías dos bloques que hacen esto. En Python los dos se escriben con while:

En bloquesEn PythonOjo
while True:True se cumple siempre. Para salir hace falta un break (lo ves abajo).
while nota != 10:La condición va al revés: «repetir hasta que sea 10» es «repetir mientras no sea 10». != quiere decir «distinto de».

while True y break

Un truco muy útil es hacer un bucle «infinito» con while True: y salir de él con break cuando ocurra algo. Este programa pide la contraseña hasta que se acierta y cuenta los intentos con un contador, como en Bucles for:

clave = "python"
intentos = 0
while True:
    escrita = input("Contraseña: ")
    intentos = intentos + 1
    if escrita == clave:
        print("Correcta. Intentos:", intentos)
        break                    # salimos del bucle
    print("Incorrecta, prueba otra vez")

Si escribes hola, 1234 y python, sale dos veces «Incorrecta, prueba otra vez» y al final «Correcta. Intentos: 3».

Pruébalo tú: mientras se cumpla…

Elige el programa y ejecútalo línea a línea. En la contraseña, la simulación escribe siempre las mismas tres respuestas para que puedas seguir la traza.

Observa que la condición del while se comprueba al principio de cada vuelta. Con while True la única salida es el break.

Sumar mientras el usuario quiera

Con while True y un acumulador puedes sumar todo lo que vaya escribiendo el usuario hasta que diga basta. Aquí «basta» es escribir -1:

total = 0
while True:
    puntos = int(input("Puntos de la ronda (-1 para terminar): "))
    if puntos == -1:
        break                    # el -1 no se suma: salimos antes
    total = total + puntos
print("Total de puntos:", total)

Practica (no se entrega)

Escribe este programa en el editor y pruébalo con 10, 25, 7 y -1. Debe salir Total de puntos: 42. Después cámbialo para que, además, cuente cuántas rondas se han jugado.

Anidamiento

Como los for, los while y los if se pueden anidar (meter unos dentro de otros). Ya lo has hecho: en la contraseña hay un if dentro de un while. Por eso el print("Correcta…") lleva 8 espacios: está dos niveles hacia dentro.
