Chuleta de Python

Un resumen para tenerlo todo a mano mientras programas y para repasar antes del cuestionario.

Mostrar y pedir

print("Hola")                 # mostrar
nombre = input("Nombre: ")    # pedir texto
edad = int(input("Edad: "))   # pedir un número entero

Variables y números

puntos = 0
pi = 3.14
puntos = puntos + 10
OperadorHace
+ - * /suma, resta, multiplica, divide
//división entera
%resto de la división
**potencia (elevado a)

Comparar

== igual · != distinto · > mayor · < menor · >= mayor o igual · <= menor o igual. Se combinan con and, or, not.

Decidir

if nota >= 5:
    print("Aprobado")
elif nota >= 4:
    print("Casi")
else:
    print("A repasar")

Repetir

for i in range(5):        # 0,1,2,3,4
    print(i)

numero = 1
while numero <= 5:
    print(numero)
    numero = numero + 1

Funciones y cadenas

def doble(n):
    return n * 2

print(doble(4))          # 8

texto = "Hola"
print(len(texto))        # 4
print(texto.lower())     # hola

Errores típicos que evitar

  • Olvidar los dos puntos : al final de if, for, while o def.
  • Olvidar la sangría de lo que va dentro.
  • Comparar con un solo = (se compara con ==; un solo = es para guardar).
  • Operar con lo que devuelve input() sin convertirlo con int() o float().
