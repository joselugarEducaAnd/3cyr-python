Mostrar y pedir

print("Hola")                 # mostrar
print("Total:", 15)           # varias cosas, separadas por comas
nombre = input("Nombre: ")    # pedir texto
edad = int(input("Edad: "))   # pedir un número entero
precio = float(input("€: "))  # pedir un número decimal

Comparar y decidir

== igual · != distinto · > mayor · < menor · >= mayor o igual · <= menor o igual. Se combinan con and, or, not.

if nota >= 5:
    print("Aprobado")
elif nota >= 4:
    print("Casi")
else:
    print("A repasar")

Repetir

for i in range(5):         # 0, 1, 2, 3, 4
    print(i)
for i in range(1, 11):     # 1 … 10 (el último no entra)
    print(i)

numero = 1
while numero <= 5:         # mientras se cumpla
    print(numero)
    numero = numero + 1

while True:                # repetir hasta un break
    dato = int(input("Número (0 para salir): "))
    if dato == 0:
        break

Sumar y contar

total = 0                  # ANTES del bucle
contador = 0
for n in range(1, 6):
    total = total + n      # acumulador: va sumando
    contador = contador + 1   # contador: va contando
print(total, contador)     # DESPUÉS del bucle: 15 5

Funciones y cadenas

def doble(n):
    return n * 2           # return entrega el resultado

print(doble(4))            # 8

texto = "Hola"
print(len(texto))          # 4
print(texto.lower())       # hola
if "o" in texto:           # ¿está la letra en el texto?
    print("Tiene o")

Errores típicos

  • SyntaxError: mal escrito. Faltan comillas, paréntesis o los dos puntos al final de if, for, while o def, o comparas con un solo = (se compara con ==).
  • IndentationError: falta (o sobra) la sangría de lo que va dentro.
  • NameError: un nombre mal escrito o una variable que todavía no existe.
  • TypeError: cuentas con lo que da input() sin convertirlo con int() o float().
  • ValueError: el usuario escribió una palabra donde iba un número.
  • Sin mensaje de error, pero sale mal: total = 0 dentro del bucle, o el print del total con sangría.
