S6 · While y anidamiento

Repetir mientras…

El bucle for repite un número conocido de veces. Pero a veces queremos repetir mientras se cumpla una condición, sin saber cuántas veces será. Para eso está el bucle while (mientras).

El bucle while

numero = 1
while numero <= 5:
    print(numero)
    numero = numero + 1
# Muestra: 1 2 3 4 5

Cuidado con el bucle infinito

Dentro del while tiene que haber algo que, tarde o temprano, haga que la condición deje de cumplirse (en el ejemplo, numero = numero + 1). Si no, el bucle no termina nunca.

while True y break

Un truco muy útil es hacer un bucle «infinito» con while True: y salir de él con break cuando ocurra algo:

import random
secreto = random.randint(1, 50)   # número al azar del 1 al 50

while True:
    intento = int(input("Adivina el número (1-50): "))
    if intento == secreto:
        print("¡Has acertado!")
        break                      # salimos del bucle
    elif intento < secreto:
        print("Demasiado bajo")
    else:
        print("Demasiado alto")

Aquí has visto también import random (una «caja de herramientas» para números al azar) y random.randint(a, b) (elige un entero al azar entre a y b).

Anidamiento

Como los for, los while y los if se pueden anidar (meter unos dentro de otros), siempre respetando la sangría de cada nivel.
